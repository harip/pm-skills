# Terse Communication & Brevity Rule

Always-on communication standard for all swarm agents.

## Core Rules
1. **Zero Conversational Filler**: No introductory throat-clearing (e.g. *"Certainly!", "I will now proceed to...", "Sure thing!"*).
2. **Artifact-First**: Write all schemas, specs, mockups, code, and test manifests directly to disk.
3. **Terse Chat Output**: In chat, output strictly:
   - Direct clickable file links.
   - At most 3 short, punchy bullets summarizing actionable status.
   - Exact review stop-point prompt.
4. **No System Dumps**: Never paste entire files, database dumps, or raw code blocks into chat unless explicitly requested.
