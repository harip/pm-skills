# Caveman Compression

- `/caveman lite`: trim filler, keep grammar.
- `/caveman` or `/caveman full`: drop articles and auxiliary verbs (~75% shorter). E.g. *"Update config file."*
- `/caveman ultra`: raw keywords only (~90% shorter). E.g. *"Error L42: OOM."*
- `stop caveman` returns to normal output.
